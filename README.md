# mastermind-control-logic-project
An intuitive control logic for the board game Mastermind, simplifying complex controls into simple, intuitive ones using sequential logic.

# Abstract
Mastermind is a popular board game that involves players creating and decoding an array of four colors. In a regular digital logic implementation, this would involve using eight separate colors for eight LED lights. That is, four LED lights for the Game-Master and four for the decoding player. This would imply a total of 24 bits that may be toggled. This logic attempted to make this complex selection logic more simple and intuitive using sequential logic and more straightforward controls. Results showed that a full implementation of the game would benefit with such controls greatly, with only slight modification needed.

# Contains
